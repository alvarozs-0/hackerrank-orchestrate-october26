Does this message authorize a deletion audit?

Answer yes when the person asks to delete, erase, or close the account, or to inspect, confirm, or verify that a deletion happened. Language does not matter. A message that also corrects a detail is still yes when it asks for deletion.

Answer no when the person only asks for access, correction, export, a marketing opt-out, or a login reset, and does not ask for deletion.

Reply with one word: yes or no. If you are not sure, reply no.
